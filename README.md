# House Price Prediction Using Machine Learning

## Project Overview
This project predicts house prices based on property features using Machine Learning.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Machine Learning

## Features
- House area
- Number of bedrooms
- Number of bathrooms
- Number of floors
- House age

## Model Evaluation
- R2 Score: 0.98
- Mean Absolute Error (MAE): 459395.8

## Output
The model predicts the estimated house price based on user inputs.

## How to Run
1. Install Python.
2. Install the required libraries.
3. Run the following command:

python main.py
